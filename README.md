# Oscar Kalid Design System

Planning and source material for a personal, agent-readable design system for
applications, dashboards, editorial reports, data stories, and polished PDF output.

The system name is intentionally undecided. `O3` is retained only as a working title;
the master brief includes a naming phase. The proposed stable documentation home is
`design.oscarkalid.com`, allowing the public name to change without breaking URLs.

## Start here

- [Master agent build brief](brief/MASTER_AGENT_BUILD_BRIEF.md) - the pasteable,
  editable source document.
- [Master agent build brief PDF](brief/MASTER_AGENT_BUILD_BRIEF.pdf) - a polished
  43-page A4 reference edition.
- [Vercel report review](references/What_decides_a_Vercel_report.pdf) - the supplied
  report-quality reference used when defining the dedicated report mode.

## What the brief covers

- Identity, naming, design principles, and signature visual rules.
- Color, typography, spacing, shape, surfaces, layout, motion, iconography,
  accessibility, localization, content, and data visualization.
- A comprehensive component inventory and component-specification contract.
- Application patterns and complete reference-product requirements.
- A separate editorial report mode for arguments, evidence, tables, charts,
  calculators, citations, print, and PDF export.
- Machine-readable tokens, implementation packages, documentation architecture,
  `llms.txt`, `llms-full.txt`, manifests, offline bundles, and agent adapters.
- An extension protocol for creating app-specific components without visual drift.
- Testing, agent-comprehension evaluation, governance, release phases, and a strict
  version 1.0 definition of done.

## Suggested agent instruction

```text
Read brief/MASTER_AGENT_BUILD_BRIEF.md in full and execute it as the project mandate.
Inspect the repository and supplied references first. Produce working artifacts, not
only a plan. Keep design.oscarkalid.com as the stable documentation domain, treat O3
as a temporary working name, and continue through the documented phases until the
release criteria are satisfied or a genuine external blocker prevents progress.
```
